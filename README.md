# APEX-COHORT-INTELLIGENCE
Apex: An enterprise-ready SaaS cohort intelligence platform. Running entirely client-side, it models customer lifetime value (LTV) using interactive Kaplan-Meier survival curves, tunes live Cox Proportional Hazards regression, and renders dynamic cohort retention heatmaps—engineered to prove predictive modeling &amp; SaaS metrics mastery.
